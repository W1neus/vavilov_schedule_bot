# 📅 Vavilov Schedule Parser & Telegram Bot

Удобный Telegram-бот и парсер расписания занятий для **Саратовского государственного университета генетики, биотехнологии и инженерии имени Н.И. Вавилова** (Вавиловский Университет).

Проект состоит из следующих основных компонентов:
1. **Парсер (`main_scraper.py`, `pdf_parser.py`)** — скачивает PDF-файлы расписания с сайта вуза, разбирает таблицы и сохраняет всё в один JSON-файл.
2. **Генератор изображений (`image_generator.py`)** — рендерит расписание в виде красивой графической сетки (картинки PNG).
3. **Telegram-бот (`tgbot/`)** — отображает меню через удобные inline-кнопки, позволяет искать пары преподавателей и отправляет сгенерированное расписание в чат.

---

## ✨ Основные возможности

*   **Автоматический сбор**: Собирает расписание по всем корпусам (УК-1, УК-2, УК-3), институтам и формам обучения (очная, заочная, очно-заочная).
*   **Удобные Inline-кнопки**: Навигация по курсам и группам в виде меню с кнопками.
*   **Два режима**: Бот работает для **Студентов** (выбор группы) и для **Преподавателей** (поиск расписания по фамилии).
*   **Поиск по преподавателям**: Быстрый поиск пар по фамилии преподавателя с поддержкой инициалов.
*   **Расписание картинкой**: Бот умеет генерировать расписание в виде изображения, чтобы его можно было сохранить на телефон.
*   **Автообновление**: Бот сам каждую полночь (по Саратову) проверяет сайт на наличие свежего расписания и обновляет его.

## 🛠 Технологический стек

*   **Язык программирования**: Python 3.10+
*   **Telegram API**: `python-telegram-bot`
*   **Сбор и разбор PDF**: `requests`, `beautifulsoup4`, `pdfplumber`
*   **База данных**: SQLite (`aiosqlite`)
*   **Картинки**: `Pillow` (для генерации сетки расписания)
*   **Часовые пояса и конфиг**: `pytz`, `python-dotenv`

## 🚀 Гайд по установке и настройке

### 📋 Предварительные требования
*   Установленный **Python 3.10** или новее.
*   Менеджер пакетов **pip**.
*   Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

### ⚡ Быстрая установка на Linux (Systemd)

Если вы ставите бота на Linux-сервер (Ubuntu/Debian/CentOS), его можно развернуть одной простой командой. Скрипт сам установит Python и системные зависимости, создаст виртуальное окружение, склонирует репозиторий, настроит службу Systemd для автозапуска и поможет интерактивно заполнить `.env`:

```bash
curl -sSL -O https://raw.githubusercontent.com/W1neus/vavilov_schedule_bot/main/setup.sh && sudo bash setup.sh
```

---

### 🔧 Ручная установка

1.  **Клонируйте репозиторий**:
    ```bash
    git clone https://github.com/W1neus/vavilov_schedule_bot.git
    cd vavilov_schedule_bot
    ```

2.  **Создайте и активируйте виртуальное окружение**:
    *   **В Windows**:
        ```bash
        python -m venv venv
        venv\Scripts\activate
        ```
    *   **В Linux/macOS**:
        ```bash
        python3 -m venv venv
        source venv/bin/activate
        ```

3.  **Установите библиотеки**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Создайте файл настроек**:
    *   Скопируйте `tgbot/.env.example` и переименовайте в `tgbot/.env`:
        ```bash
        cp tgbot/.env.example tgbot/.env
        ```
    *   Откройте `.env` и укажите ваш токен бота и ID админов:
        ```env
        BOT_TOKEN=ваш_токен_бота_здесь
        ADMIN_IDS=123456789
        ```

## 🏃‍♂️ Запуск бота

Для запуска бота выполните:
```bash
python tgbot/main.py
```
> **Примечание**: При первом запуске бот сам автоматически проверит сайт, скачает и распарсит расписание (файл `data/schedule.json` создастся сам). 
> Если вы хотите принудительно запустить сбор расписания вручную, вы можете выполнить: `python main_scraper.py`.
